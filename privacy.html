TEDDY 개인정보 처리방침

TEDDY는 Brity 메신저 쪽지를 읽어 할 일과 일정을 정리하는 Windows 프로그램입니다. 쪽지와 일정은 사용자의 PC에 저장하며, TEDDY 개발자는 이 정보를 받는 서버를 두지 않습니다. AI 모드를 켜면 분류에 필요한 정보가 사용자가 선택한 서비스로 전송됩니다. AI 비서 연결을 켜면 연결한 AI 앱이 TEDDY의 일정 정보를 읽고 일정을 등록·수정할 수 있습니다. 구글 캘린더 보내기는 준비 중인 기능으로, 현재 버전에서는 동작하지 않습니다.

1. 이 PC에 저장하는 정보

TEDDY는 아래 정보를 사용자의 Windows 계정 폴더(%APPDATA%\TEDDY)에 저장합니다. 백업 파일은 사용자가 선택한 위치에 별도로 저장됩니다.

정보내용
가져온 쪽지쪽지 제목, 본문, 보낸 사람, 보낸 사람의 소속, 보낸 시각, 수신자 목록, 첨부파일의 이름과 위치
프로필별명, 소속 기관과 학교급, 교사·교직원 구분, 담임 여부와 학년·반, 담당 교과, 소속 부서, 직위, 담당 업무
일정제목, 내용, 날짜와 시각, 장소, 반복, 태그, 참고자료 파일의 경로, 완료·중요 표시
설정동기화 예약, 단축키, AI 연결 방식, API 키, 구글 캘린더 연결 정보

API 키와 구글 로그인 정보(갱신 토큰)는 Windows가 제공하는 암호화 저장 기능으로 암호화해 저장합니다.

2. Brity 메신저 쪽지를 읽는 방법

TEDDY는 사용자가 ‘지금 동기화’를 누르거나 예약한 시각이 되면, 이 PC에 열려 있는 Brity 메신저 창의 내용을 Windows의 화면 읽기 기능(UI Automation)으로 읽습니다. Brity 메신저의 서버에 접속하거나 Brity 계정의 비밀번호를 다루지 않습니다.

3. AI 모드를 켰을 때

AI 모드는 사용자가 선택한 AI 서비스를 이용해 쪽지의 내용을 분류하고 일정과 마감을 찾는 선택 기능입니다. 처음에는 꺼져 있습니다. 꺼져 있으면 쪽지는 이 PC 안의 규칙으로만 분류되고 인터넷으로 보내지지 않습니다.

사용자가 AI 모드를 켜면, 고른 서비스로 아래 정보를 보내 분류를 요청합니다. 보내는 곳은 OpenAI(ChatGPT), Anthropic(Claude), Google(Gemini) 가운데 사용자가 연결한 곳, 또는 사용자가 직접 입력한 API 주소입니다.

보내는 정보쪽지 제목과 본문, 발신 시각과 소속, 분류에 쓰는 업무 프로필(소속 기관과 부서, 학년·반, 직위와 담당 업무). 개인정보 전송 최소화를 끄면 발신자 이름도 포함됩니다. 단축키로 등록할 때는 선택한 글과 등록 시각, 업무 프로필을 보냅니다.
보내지 않는 정보Brity 수신자 목록, 첨부파일의 이름·내용·경로, 프로필 별명, 사용자가 직접 만든 일정과 메모, 본문에 인용된 이전 쪽지
가려서 보내는 정보개인정보 전송 최소화(기본값 켜짐)가 켜져 있으면, 규칙으로 찾은 학생·학부모 이름, 연락처, 주소, 주민등록번호, 계좌번호, 건강·가정 형편에 관한 내용을 가리고, 보낸 사람의 이름은 빼고 보냅니다.

규칙이 찾지 못한 개인정보는 그대로 전송될 수 있습니다. 보낸 정보는 각 서비스의 개인정보 처리방침에 따라 처리됩니다. TEDDY는 분류 결과를 이 PC에 저장합니다.

3-1. AI 비서를 연결했을 때

AI 비서 연결은 사용자가 설정에서 고른 AI 앱(Claude 데스크톱 앱, Claude Code, ChatGPT(Codex) 앱, Gemini(Antigravity))이 TEDDY의 일정을 읽고 등록·수정·삭제할 수 있게 하는 선택 기능입니다. 처음에는 연결되어 있지 않습니다. 연결하면 TEDDY는 그 앱의 설정 파일에 TEDDY 항목만 더하고, 처음 고칠 때 원래 파일을 ‘.teddy-backup’으로 남깁니다.

AI 앱이 읽을 수 있는 정보일정의 제목, 분류, 날짜와 시각, 장소, 태그, 중요·완료 여부, 반복 규칙, 등록 경로(쪽지·직접 등록·AI 비서), AI 비서가 등록할 때 알려 준 자료 이름, 직접 만든 일정과 AI 비서가 만든 일정의 내용(메모), 업무 프로필(소속 기관과 부서, 학년·반, 직위와 담당 업무), 오늘 날짜
보내지 않는 정보Brity 쪽지의 본문·제목·발신자·수신자, 쪽지에서 찾은 근거 구절, 첨부파일, 프로필 별명, API 키와 설정
보내는 곳사용자가 연결한 AI 앱과 그 앱의 AI 서비스(Anthropic, OpenAI, Google). AI 앱에 올린 자료와 대화는 그 서비스의 방침에 따라 처리됩니다.

TEDDY와 AI 앱은 같은 PC 안에서만 이야기하며, 그 Windows 사용자 계정의 프로그램만 요청할 수 있습니다. 연결은 설정의 ‘AI 비서 연결’에서 언제든 끊을 수 있습니다.

4. 구글 캘린더로 보낼 때

이 기능은 준비 중이며, 현재 버전의 TEDDY는 구글 계정에 연결하거나 구글로 정보를 보내지 않습니다. 기능을 제공하게 되면 아래와 같이 동작합니다.

구글 캘린더 보내기는 사용자가 설정에서 자기 구글 계정을 연결했을 때만 동작합니다. 일정은 연결한 사용자 본인의 구글 계정으로만 보내지며, TEDDY 개발자를 거치지 않습니다.

요청하는 권한

TEDDY는 구글 계정에 https://www.googleapis.com/auth/calendar.app.created 권한 하나만 요청합니다. 이 권한으로 TEDDY는 자신이 만든 캘린더와 그 안의 일정만 만들고, 고치고, 지울 수 있습니다. 사용자의 다른 캘린더와 일정, Gmail, 연락처, 드라이브 등 다른 구글 데이터는 읽거나 바꾸지 않습니다.

보내는 정보

연결하면 사용자의 구글 계정에 ‘TEDDY’ 캘린더를 하나 만들고, 그 안에 일정의 제목, 날짜와 시각, 장소, 내용(분류와 메모), 반복 규칙, 완료·중요 표시를 보냅니다. 쪽지 원문과 프로필은 보내지 않습니다.

구글 사용자 데이터의 제한적 사용

TEDDY가 Google API에서 받은 정보를 사용하고 다른 앱으로 옮기는 일은 제한적 사용 요건을 포함한 Google API 서비스 사용자 데이터 정책을 따릅니다.

TEDDY는 구글에서 받은 정보를 사용자가 요청한 일정 보내기에만 쓰며, 광고에 쓰거나 다른 사람에게 넘기거나 팔지 않습니다. 사람이 이 정보를 읽는 일도 없습니다.

5. 제3자 제공과 판매

TEDDY 개발자는 사용자의 정보를 받지 않으므로 제3자에게 제공하거나 판매하지 않습니다. TEDDY에는 광고나 이용 통계 수집 도구가 들어 있지 않습니다. 위 3, 4항처럼 사용자가 켠 기능에서 정보를 보내는 곳은 사용자가 고른 서비스뿐입니다.

6. 보관 기간과 삭제

  • 이 PC의 정보는 사용자가 지울 때까지 보관됩니다. 설정의 데이터 관리에서 ‘데이터 초기화’를 누르면 프로필, 일정, 쪽지, 설정이 모두 지워집니다.
  • 프로그램을 지워도 기록 폴더가 남을 수 있으니, 기록을 모두 지우려면 먼저 데이터 초기화를 하세요. 따로 만든 백업 파일은 저장한 위치에서 직접 삭제해야 합니다.
  • 구글 연결은 설정에서 ‘연결 끊기’로 끊을 수 있고, 구글 계정의 서드파티 연결 관리에서도 TEDDY의 권한을 거둘 수 있습니다. 이미 보낸 TEDDY 캘린더는 구글 캘린더에서 직접 지울 수 있습니다.
  • AI 서비스로 보낸 정보의 보관은 각 서비스의 방침을 따릅니다.

7. 안전하게 지키는 방법

  • API 키와 구글 갱신 토큰은 Windows의 암호화 저장 기능으로 암호화합니다.
  • 구글 로그인은 사용자의 웹브라우저에서 구글 화면으로 직접 하며, TEDDY는 구글 비밀번호를 받지 않습니다.
  • 외부 API 서버에 직접 연결할 때는 HTTPS 주소를 사용합니다. 같은 PC에서 실행하는 로컬 API 서버에 한해 HTTP 주소도 사용할 수 있습니다.
  • PC에 저장된 정보는 그 PC의 Windows 계정 보안에 따라 보호되므로, PC 잠금과 계정 비밀번호를 지켜 주세요.

8. 학생과 학부모 정보

학교 쪽지에는 학생과 학부모의 정보가 들어 있을 수 있습니다. TEDDY는 이 정보를 이 PC에만 저장하며, AI 모드와 개인정보 전송 최소화를 함께 켜면 규칙으로 찾은 이름과 연락처를 가려서 보냅니다. TEDDY는 아동이 직접 쓰는 프로그램이 아니며, 아동으로부터 정보를 받지 않습니다.

9. 이용자의 권리

사용자는 언제든 TEDDY 화면에서 자신의 정보를 보고, 고치고, 지울 수 있습니다. AI 모드와 구글 캘린더 보내기는 언제든 끌 수 있습니다. 정보가 개발자에게 저장되지 않으므로, 열람이나 삭제는 사용자의 PC에서 바로 할 수 있습니다.
